# Lisensi Konten

Hak cipta (c) 2026 Restkand. Semua hak dilindungi.

Lisensi untuk konten di folder `src/content/` (artikel, pelajaran, istilah Kamus, beserta teks, diagram, dan soal kuis di dalamnya) sedang disiapkan dan akan diumumkan di file ini.

Sampai saat itu, konten boleh dibaca di situs dan di repositori ini. Menyalin, menyebarluaskan, mengubah, atau memakai ulang konten di luar itu membutuhkan izin tertulis dari pemilik. Fitur bawaan GitHub seperti melihat dan fork tetap berlaku sesuai Ketentuan Layanan GitHub.

Kode situs dilisensikan terpisah di bawah MIT: lihat [LICENSE](LICENSE).

## Pengecualian

Kutipan, logo, merek dagang, dan materi pihak ketiga yang dirujuk di dalam konten tetap milik pemiliknya masing-masing.

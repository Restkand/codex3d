Siapa pun bisa berkontribusi, tidak harus programmer. Koreksi salah ketik pun membantu, begitu juga perbaikan fakta, artikel baru, studi kasus, terjemahan, dan ulasan dari praktisi.

## Jenis kontribusi

| Jenis | Cara tercepat |
| --- | --- |
| Koreksi kecil (typo, kalimat membingungkan) | Tautan **Edit halaman ini di GitHub** di bawah setiap halaman |
| Koreksi fakta atau sumber usang | Buka issue **Koreksi fakta** di GitHub |
| Usulan topik atau artikel | Buka issue **Usulan artikel** dulu, agar tidak dobel dengan kontributor lain |
| Menulis artikel atau pelajaran | Pull request, mengikuti [Menulis artikel](/kontribusi/menulis-artikel/) |
| Meninjau sebagai praktisi | Komentari pull request atau issue, lalu namamu dicantumkan di `reviewers` |

## Koreksi kecil langsung dari browser

1. Klik **Edit halaman ini di GitHub** di bagian bawah halaman yang ingin diperbaiki. GitHub akan membuka file Markdown-nya.
2. Lakukan perubahan, lalu pilih **Propose changes**. GitHub otomatis membuat salinan (fork) untukmu.
3. Klik **Create pull request** dan jelaskan singkat apa yang diubah dan kenapa.

## Menjalankan situs di komputer sendiri

Dibutuhkan [Node.js](https://nodejs.org/) versi 22 atau lebih baru.

```sh
git clone https://github.com/Restkand/krekit.git
cd krekit
npm install
npm run dev
```

Situs berjalan di alamat yang ditampilkan terminal. Setiap file yang disimpan langsung terlihat di browser. Sebelum membuat pull request, jalankan `npm run build` untuk memastikan tidak ada error.

<Aside type="tip" title="Jaringan kantor">
Jika `npm install` gagal dengan error sertifikat (misalnya `UNABLE_TO_VERIFY_LEAF_SIGNATURE`), jaringanmu kemungkinan memeriksa lalu lintas HTTPS. Jalankan dengan sertifikat sistem: `NODE_OPTIONS=--use-system-ca npm install`.
</Aside>

## Proses tinjauan

- Setiap pull request konten ditinjau minimal oleh satu pengelola.
- Konten baru masuk dengan status **draf** dan baru menjadi **ditinjau** setelah diperiksa oleh orang yang berpengalaman di bidangnya.
- Klaim fakta tanpa sumber akan diminta sumbernya sebelum digabungkan.

Sebelum pull request pertamamu digabungkan, bot CLA Assistant akan memintamu menyetujui [Perjanjian Lisensi Kontributor](https://github.com/Restkand/krekit/blob/main/CLA.md). Hak cipta tetap milikmu. Kontribusi konten terbit di bawah CC BY-NC-SA 4.0 dan kontribusi kode di bawah MIT. Semua kontributor mengikuti [Kode etik](https://github.com/Restkand/krekit/blob/main/CODE_OF_CONDUCT.md).

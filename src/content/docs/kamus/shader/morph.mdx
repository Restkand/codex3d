Mengubah satu bentuk menjadi bentuk lain dengan [lerp](/kamus/ruang/lerp/) posisi setiap titik: `posisi = lerp(bentuk_A, bentuk_B, t)`. Syaratnya, kedua bentuk punya **jumlah dan urutan titik yang sama**, sehingga setiap titik di bentuk A tahu pasangannya di bentuk B.

Ada dua cara memakainya:

- **Blend shape (morph target):** bentuk B dibuat artist di aplikasi 3D (di Blender disebut *shape key*), disimpan di mesh, lalu dicampur saat game berjalan. Ini cara standar untuk **ekspresi wajah** dan sinkronisasi bibir, karena wajah sulit digerakkan hanya dengan tulang.
- **Dihitung di vertex shader:** bentuk B tidak disimpan, tetapi dihitung dengan rumus. Cocok untuk efek seperti objek menggelembung, meleleh, atau berubah menjadi bola.

## Di engine

<EngineTabs>
<div slot="unity">

Disebut **BlendShapes**, diatur di komponen **Skinned Mesh Renderer**. Lewat kode:

```csharp
skinnedMeshRenderer.SetBlendShapeWeight(indeks, 100f);
```

Rentang bobotnya mengikuti batas minimum dan maksimum yang tersimpan di model. Untuk blend shape dari file FBX hasil impor, 0 berarti blend shape tidak berpengaruh dan 100 berarti pengaruhnya penuh. Jadi skalanya 0 sampai 100, tidak 0 sampai 1.

</div>
<div slot="unreal">

Disebut **Morph Targets**, diimpor bersama Skeletal Mesh. Lewat Blueprint: `Set Morph Target`.

</div>
<div slot="godot">

Disebut **Blend Shapes** pada `MeshInstance3D`. Lewat kode:

```gdscript
var i := find_blend_shape_by_name("Senyum")
set_blend_shape_value(i, 1.0)
```

Nilai 0 berarti blend shape tidak berpengaruh, dan makin besar nilainya makin kuat pengaruhnya. `find_blend_shape_by_name` mengembalikan `-1` jika namanya tidak ditemukan.

</div>
</EngineTabs>

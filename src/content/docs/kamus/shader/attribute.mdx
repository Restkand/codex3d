Data yang **berbeda untuk setiap vertex**: posisi, [normal](/kamus/geometri/normal/), [UV](/kamus/geometri/uv/), warna vertex, dan untuk karakter beranimasi, bobot tulang. Disimpan di mesh dan dibaca vertex shader.

Bandingkan dengan [uniform](/kamus/shader/uniform/), yang nilainya sama untuk semua titik.

**Warna vertex** sering dipakai sebagai data tambahan, bukan sebagai warna. Misalnya, artist mengecat ujung rumput dengan merah dan pangkalnya hitam, lalu vertex shader memakai nilai merah itu sebagai "seberapa jauh titik ini boleh bergoyang".

## Di engine

<EngineTabs>
<div slot="unity">

Shader Graph: node **Position** dan **Normal Vector** (pilih ruangnya lewat dropdown Space: Object, View, World, Tangent), **UV** (dropdown Channel UV0 sampai UV7), dan **Vertex Color**.

Di HLSL URP, attribute ditulis sebagai struct input vertex yang lazim dinamai `Attributes`, dengan semantik untuk setiap data: `POSITION`, `NORMAL`, `TEXCOORD0`, `COLOR`.

```hlsl
struct Attributes
{
    float4 positionOS : POSITION;
    float3 normalOS   : NORMAL;
    float2 uv         : TEXCOORD0;
    float4 color      : COLOR;
};
```

</div>
<div slot="unreal">

Node **TexCoord**, **VertexNormalWS**, **Vertex Color**, dan **Absolute World Position**.

</div>
<div slot="godot">

Variabel bawaan di fungsi `vertex()`: `VERTEX`, `NORMAL`, `UV`, `UV2`, `COLOR`. Secara bawaan `VERTEX` dan `NORMAL` berada di ruang model (lokal objek), kecuali kamu memakai `render_mode world_vertex_coords`.

</div>
</EngineTabs>

Kumpulan tiga angka (x, y, z). Angka yang sama bisa berarti tiga hal berbeda, tergantung pemakaiannya: **posisi** (titik di ruang), **arah** (ke mana), atau **skala** (seberapa besar di setiap sumbu).

```text title="Pseudocode"
posisi = (1, 0, -2)
posisi.x = posisi.x + 0.5
arah_ke_target = posisi_target - posisi_saya   // selisih dua posisi = arah
```

## Di engine

<EngineTabs>
<div slot="unity">

`Vector3` (dan `Vector2` untuk 2D), dengan komponen bertipe `float`. Contoh: `transform.position = new Vector3(1, 0, -2);`

</div>
<div slot="unreal">

`FVector`. Di Unreal Engine 5, komponennya bertipe `double` agar dunia yang sangat luas tetap presisi. Contoh: `SetActorLocation(FVector(100.f, 0.f, 0.f));`

</div>
<div slot="godot">

`Vector3` (dan `Vector2` untuk 2D). Komponennya secara bawaan float 32-bit, kecuali engine dikompilasi dengan opsi `precision=double`. Contoh: `position = Vector3(1, 0, -2)`

</div>
</EngineTabs>

Ketiga engine menyediakan operasi vektor yang sering dipakai sebagai fungsi siap pakai: panjang, normalisasi, jarak, [dot product](/kamus/ruang/dot/), [cross product](/kamus/ruang/cross/), dan interpolasi.

**NDC** (*Normalized Device Coordinates*) adalah koordinat layar yang dinormalisasi: rentang −1..1 di setiap sumbu, dengan (0, 0) di tengah layar. Dengan cara ini, logika yang sama berlaku di layar ukuran apa pun. GPU memakainya setelah [proyeksi](/kamus/ruang/matrices/), dan game memakainya untuk mengubah posisi kursor menjadi sinar ke dunia 3D.

```text title="Pseudocode: piksel → NDC (asal piksel di kiri atas)"
x_ndc = (x_piksel / lebar_layar) * 2 - 1
y_ndc = -((y_piksel / tinggi_layar) * 2 - 1)   // dibalik: Y layar ke bawah, Y NDC ke atas
```

## Di engine

Engine menyediakan fungsi untuk langsung mengubah posisi kursor menjadi sinar ke dunia 3D, jadi rumus di atas jarang ditulis sendiri. Yang perlu diperhatikan adalah letak titik asal koordinat layar di tiap engine:

<EngineTabs>
<div slot="unity">

`Input.mousePosition` dalam piksel, dihitung dari **kiri bawah** layar: (0, 0) di kiri bawah, (`Screen.width`, `Screen.height`) di kanan atas. API ini bagian dari Input Manager lama; Unity menyarankan proyek baru memakai paket **Input System**.

`Camera.main.ScreenPointToRay(posisi)` menghasilkan sinar di world space yang berawal di near plane kamera dan melewati titik layar itu. Fungsi ini juga memakai asal kiri bawah dan mengabaikan komponen z.

</div>
<div slot="unreal">

Posisi layar dihitung dari **kiri atas**. `APlayerController::DeprojectScreenPositionToWorld()` menghasilkan titik dan arah sinar di dunia.

</div>
<div slot="godot">

Posisi kursor didapat dari `event.position` pada event mouse, atau `get_viewport().get_mouse_position()`. Keduanya dalam koordinat viewport, dan seperti koordinat 2D Godot lainnya, asalnya di **kiri atas** dengan Y ke bawah.

`camera.project_ray_origin(posisi)` dan `camera.project_ray_normal(posisi)` menghasilkan titik awal dan arah sinar di world space. Kebalikannya, `camera.unproject_position(titik_dunia)` memberi posisi di layar untuk sebuah titik 3D, berguna untuk menempelkan label di atas kepala karakter.

</div>
</EngineTabs>

API bawaan browser untuk menyuruh GPU menggambar grafis 2D/3D di dalam elemen `<canvas>`. Sangat rendah-level: kamu harus mengirim titik, shader, dan buffer secara manual.

<Aside type="note" title="Analogi">
WebGL adalah bahasa mesin dapur; Three.js adalah koki yang menerjemahkan "buatkan nasi goreng" menjadi ratusan instruksi kecil.
</Aside>

**Di proyek ini:** `src/experiment/core/setup.js`

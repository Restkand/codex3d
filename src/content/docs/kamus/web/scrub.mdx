Progres timeline (0..1) diikat langsung ke posisi scroll: scroll maju = animasi maju, scroll mundur = mundur. `scrub: true` mengikatnya tanpa jeda; `scrub: 1` membuat animasi butuh 1 detik untuk mengejar posisi scroll, sehingga terasa halus.

**Di proyek ini:** `src/experiment/scroll.js`

Pustaka JavaScript 3D yang membungkus API grafis browser menjadi konsep yang mudah dipahami: scene, kamera, mesh, cahaya, material. Dengan `WebGLRenderer`, yang dipakai situs ini, Three.js tetap menghasilkan perintah WebGL 2 di belakang layar. Three.js juga punya `WebGPURenderer` untuk API WebGPU.

Perbandingan piksel fisik layar dengan piksel CSS. Di layar beresolusi tinggi nilainya lebih dari 1, dan zoom halaman ikut mengubahnya. Kanvas 1000×500 piksel CSS dengan DPR 2 dirender 2000×1000 piksel fisik, yaitu 4x jumlah piksel. Proyek ini membatasi DPR ke 1,5 agar stabil.

## Pelajari lebih dalam

Elemen `<canvas>` punya dua ukuran: atribut `width/height` (resolusi gambar, jumlah piksel yang dirender) dan ukuran CSS (seberapa besar ditampilkan). `renderer.setSize(w, h)` mengatur ukuran CSS = w × h dan resolusi = w × h × pixelRatio (dibulatkan ke bawah).

Teknik lanjutan: **adaptive resolution**. Pantau FPS; jika turun di bawah target selama beberapa detik, turunkan pixel ratio sedikit demi sedikit. Jika stabil, naikkan lagi. Cara ini membantu aplikasi tetap lancar di perangkat lemah.

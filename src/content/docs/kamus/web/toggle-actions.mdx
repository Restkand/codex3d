Kebalikan dari scrub: animasi dipicu saat elemen masuk/keluar area, lalu berjalan dengan durasinya sendiri. Format: `"onEnter onLeave onEnterBack onLeaveBack"` (bawaannya `"play none none none"`), contohnya `"play none none reverse"`. Callback `onToggle` dipanggil saat ScrollTrigger berganti dari tidak aktif ke aktif atau sebaliknya.

**Di proyek ini:** `src/experiment/scroll.js` (`toggleActions`), `src/experiment/transitions.js` (`onToggle`)

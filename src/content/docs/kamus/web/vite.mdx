Dev server + bundler. Saat dev, file dilayani sebagai ES module native dan perubahan diterapkan otomatis saat file disimpan (HMR). Perintah build menggabungkan dan mengecilkan semuanya ke folder `dist/` untuk dipublikasikan.

Proyek ini memakai [Astro](https://astro.build/), framework situs yang memakai Vite di dalamnya. Semua fitur Vite, seperti HMR dan import `?raw` untuk shader, tetap berlaku, dan `npm run build` menjalankan build Astro. Konfigurasinya ditulis di `astro.config.mjs` (opsi Vite tambahan masuk ke kunci `vite`), tanpa `vite.config.js`.

**Di proyek ini:** `astro.config.mjs`

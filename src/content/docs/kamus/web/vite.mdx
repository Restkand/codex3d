Dev server + bundler. Saat dev, file dilayani apa adanya sebagai ES module dan halaman diperbarui otomatis saat file disimpan (HMR). `npm run build` menggabungkan dan mengecilkan semuanya ke folder `dist/` untuk dipublikasikan.

Proyek ini memakai [Astro](https://astro.build/), framework situs yang dibangun di atas Vite. Semua fitur Vite, seperti HMR dan import `?raw` untuk shader, tetap berlaku. Konfigurasinya ditulis di `astro.config.mjs`, bukan di `vite.config.js`.

**Di proyek ini:** `astro.config.mjs`

Fitur Vite: menambahkan `?raw` di akhir path mengimpor isi file sebagai string. Cara praktis menyimpan shader di file `.glsl` terpisah (dengan syntax highlighting) alih-alih string panjang di JavaScript.

```js
import vertexShader from '../shaders/hologram/vertex.glsl?raw'
```

**Di proyek ini:** `src/experiment/world/hologram.js`

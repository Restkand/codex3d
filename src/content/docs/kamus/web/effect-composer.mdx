Pengelola rangkaian efek. Pass dijalankan sesuai urutan ditambahkan; setiap pass membaca gambar dari pass sebelumnya (di ShaderPass lewat uniform `tDiffuse`) dan menulis hasil baru, dan pass terakhir otomatis tampil di layar. Proyek ini: RenderPass → ShaderPass (glitch) → OutputPass. RenderPass menggambar scene; setiap pass efek sesudahnya berarti satu kali lagi menggambar layar penuh.

**Di proyek ini:** `src/experiment/post.js`

Pass terakhir di composer: menerapkan tone mapping dan konversi ke color space keluaran renderer (bawaannya sRGB), dengan pengaturan yang diambil dari renderer. Saat render langsung ke layar, renderer melakukannya sendiri. Saat memakai composer, scene digambar ke render target, tempat renderer tidak menerapkan keduanya, sehingga tugas itu berpindah ke OutputPass.

**Di proyek ini:** `src/experiment/post.js`

Plugin GSAP yang menghubungkan animasi dengan posisi scroll. `start`/`end` memakai format "bagian-elemen bagian-viewport", contohnya `"top center"` = saat atas elemen menyentuh tengah layar.

<Aside type="tip" title="Quest">
Aktifkan `markers: true` di scroll.js untuk melihat garis start/end.
</Aside>

**Di proyek ini:** `src/experiment/scroll.js`

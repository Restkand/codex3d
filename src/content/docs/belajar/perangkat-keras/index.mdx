Game yang lancar di PC kerja bisa patah-patah di laptop pemain, dan game di HP bisa turun FPS-nya setelah sepuluh menit dimainkan. Penyebabnya ada di perangkat keras: berapa banyak pekerjaan yang sanggup diselesaikan CPU dan GPU dalam satu frame, seberapa cepat data berpindah dari memori, dan seberapa lama perangkat bisa bekerja keras sebelum kepanasan. Bab tambahan ini menjelaskan bagian-bagian itu dari sudut pandang pembuat game.

## Untuk siapa

Semua peran. Programmer memakainya untuk optimasi, artist untuk menentukan anggaran tekstur dan poligon, dan produser untuk menetapkan spesifikasi target. Bab ini melengkapi [Fondasi Engine](/belajar/fondasi-engine/), terutama [Pelajaran 1](/belajar/fondasi-engine/01-frame/) dan [Pelajaran 8](/belajar/fondasi-engine/08-profiling/).

## Rencana isi

1. **CPU.** Core dan thread, kenapa main thread sering menjadi batas, cache, dan pekerjaan apa saja yang ditanggung CPU dalam satu frame.
2. **GPU.** Shader core, VRAM, bandwidth memori, serta perbedaan GPU terintegrasi dan GPU terpisah.
3. **Memori dan penyimpanan.** RAM dan VRAM, waktu muat, dan streaming aset dari SSD atau HDD.
4. **Layar.** Resolusi, refresh rate, V-Sync, dan variable refresh rate.
5. **Platform.** PC, konsol, HP, dan handheld PC. Di HP: GPU tile-based, panas dan thermal throttling, serta baterai.
6. **Menentukan spesifikasi.** Cara menetapkan spesifikasi target dan minimal, membaca lembar spesifikasi, dan perbedaan benchmark dengan profiling.

## Istilah Kamus yang direncanakan

Bab Kamus baru tentang perangkat keras: core dan thread, cache, VRAM, bandwidth memori, GPU terintegrasi, thermal throttling, dan variable refresh rate.

## Standar khusus bab ini

Perbandingan perangkat ditulis berdasarkan kriteria, tanpa merekomendasikan merek tertentu. Angka spesifikasi wajib menautkan lembar data resmi produsen, dengan tanggal akses. Jika suatu saat ada kerja sama dengan produsen perangkat keras, kerja sama itu diungkap di halaman terkait dan tidak mengubah penilaian, sesuai halaman [Kemitraan](/kemitraan/) dan [Standar konten](/kontribusi/standar-konten/).
